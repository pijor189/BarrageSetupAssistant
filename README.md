# Barrage Setup Assistant
![CI](https://github.com/pijor189/BarrageSetupAssistant/actions/workflows/ci.yml/badge.svg)
[![codecov](https://codecov.io/gh/pijor189/BarrageSetupAssistant)

Barrage Setup Assistant to pomysł na aplikację, która będzie w sposób zautomatyzowany
poprawnie losować wszystkie potrzebne składowe do rozegrania rozgrywki w Barrage. 

W tym celu została napisana aplikacja wykorzystując język Python. Do testów użyta została biblioteka pytest.
Wszystkie potrzebne informacje będą zczytywane z pliku json.
